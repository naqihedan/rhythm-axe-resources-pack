# Rhythm Axe 资源包

《节奏地图》rhythm_axe 的配套资源包（Minecraft Java Edition）。

| 配套项目 | 地址 |
| --- | --- |
| 数据包 | https://github.com/naqihedan/rhythm_axe-datapack |
| 前置模组 | https://github.com/naqihedan/rhythm_axe_mod |

## 仓库内容

| 目录 | 说明 |
| --- | --- |
| `assets/minecraft/` | 覆写的原版贴图 |
| `assets/rhythm_axe/` | 物品模型、模型定义、音效定义、贴图 |
| `BB模型/` | Blockbench 源模型与生成脚本（开发用） |
| `_tools/` | 贴图 / 模型生成脚本（开发用） |

> **本仓库不包含音效音频文件。**
> `assets/rhythm_axe/sounds/` 下的 `*.ogg` / `*.xmp` 因版权原因未纳入版本管理，直接克隆本仓库时音效会缺失，需要完整音效请从正式发布渠道获取资源包。
